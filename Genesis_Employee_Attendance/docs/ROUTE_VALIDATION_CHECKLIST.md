# ধাপ ৫: রুট ও স্পিড সঠিককরণ — টেস্ট ও ভ্যালিডেশন চেকলিস্ট

পরিকল্পনা অনুযায়ী বাস্তবায়ন যাচাই করতে এই চেকলিস্ট অনুসরণ করুন।

---

## ১. গাড়ি টেস্ট (৩০–৪০ কিমি/ঘণ্টা)

**সময় স্লট:** ০১:৪৫ PM – ০২:৪১ PM এর মতো একটি স্লটে আবার টেস্ট করুন (গাড়িতে ৩০–৪০ কিমি/ঘণ্টা)।

| # | চেক | কীভাবে যাচাই করবেন | সম্পন্ন |
|---|-----|---------------------|---------|
| 1.1 | লগে পয়েন্টের ব্যবধান ১ মিনিটের চেয়ে কম | `/admin/tracking/locationlog/` এ EMP009 (অথবা টেস্ট এমপ্লয়ি) দিয়ে ফিল্টার করুন। তারিখ ও সময় ০১:৪৫–০২:৪১ সিলেক্ট করে লগ দেখুন। দুটি পরপর টাইমস্ট্যাম্পের ব্যবধান ১৫–২০ সেকেন্ড (অথবা ৩০ মিটার ডিসপ্লেসমেন্ট অনুযায়ী) হওয়া উচিত যখন গাড়ি চলছে। | ☐ |
| 1.2 | রুট ম্যাপে কম জিগজ্যাগ | ড্যাশবোর্ড → Route History → একই এমপ্লয়ি, তারিখ, ১৩:৪৫–১৪:৪১ টাইম রেঞ্জ দিয়ে রুট লোড করুন। নীল লাইন Catmull-Rom স্মুদিং সহ দেখাবে; রাস্তার কাছাকাছি এবং আগের চেয়ে কম জিগজ্যাগ। | ☐ |
| 1.3 | ডিসট্যান্স যৌক্তিক (কিমি) | রুট সামারিতে Distance: X.XX km দেখাবে। দূরত্ব যৌক্তিক (টেস্ট রুটের আনুমানিক দৈর্ঘ্যের কাছাকাছি)। | ☐ |
| 1.4 | সেগমেন্ট স্পিড ৩০–৪০ কিমি/ঘণ্টার কাছাকাছি | রুট সামারিতে **Avg speed (computed):** XX.X km/h দেখাবে। গাড়ি ৩০–৪০ কিমি/ঘণ্টায় চললে এই মান সেই রেঞ্জের কাছাকাছি হওয়া উচিত। **Device:** XX.X km/h (যদি থাকে) আলাদা দেখাবে। | ☐ |

## ৩. অটোমেটেড টেস্ট (ব্যাকেন্ড)

Docker ব্যবহার করলে কন্টেইনারের ভেতর টেস্ট চালান (PostGIS/GDAL ইতিমধ্যে ইমেজে থাকে):

```bash
cd Genesis_Employee_Attendance
docker compose run --rm web python manage.py test tracking.tests.RouteHistorySerializerTest -v 2
```

অথবা যদি `web` সার্ভিস ইতিমধ্যে চালু থাকে:

```bash
docker compose exec web python manage.py test tracking.tests.RouteHistorySerializerTest -v 2
```

সব টেস্ট পাস হলে ধাপ ২ (ডিসট্যান্স, স্পিড, একুরেসি ফিল্টার) সঠিকভাবে কাজ করছে ধরে নেওয়া যায়।

## ৪. সংক্ষিপ্ত রেফারেন্স

- **লোকেশন ফ্রিকোয়েন্সি:** মোবাইল অ্যাপ `app_config.dart` → `locationUpdateIntervalSecondsWhenMoving`, `minDisplacementToSendMeters`; `background_worker.dart` → অ্যাডাপ্টিভ টাইমার।
- **রুট স্মুদিং:** ড্যাশবোর্ড `map_tracking.js` → `smoothPolyline()` + `drawRoute()`।
- **ডিসট্যান্স/স্পিড:** ব্যাকেন্ড `tracking/serializers.py` → `get_route_history()` (মিটার, সেগমেন্ট স্পিড, গড় স্পিড)।
- **স্পিড ডিসপ্লে:** রুট হিস্টরি পেজে Avg speed (computed) ও Device; লাইভ পপআপে Device।

এই চেকলিস্ট সম্পন্ন হলে ধাপ ৫ (টেস্ট ও ভ্যালিডেশন) সম্পূর্ণ বলে ধরা হবে।
