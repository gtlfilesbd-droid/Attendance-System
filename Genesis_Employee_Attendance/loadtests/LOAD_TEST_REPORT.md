## যা ঠিক করা হয়েছে (Vul Fix)

1. **অথেন্টিকেশন:** `on_start`-এ `/api/employees/auth/login/` দিয়ে লগইন করা এবং JWT + `employee` id নেওয়া।  
   `LOCUST_TEST_EMAIL` ও `LOCUST_TEST_PASSWORD` সেট করলে সব ভার্চুয়াল ইউজার এই একই টোকেন দিয়ে রিকোয়েস্ট করবে এবং **2xx** পাবে।

2. **পাথ:** সব রিকোয়েস্ট সঠিক API পাথে যাচ্ছে:
   - `POST /api/tracking/log-location/`
   - `POST /api/tracking/log-location/bulk/`
   - `GET /api/attendance/my-attendance/?start_date=...&end_date=...`

3. **পেলোড:** লগইন সফল হলে `employee` ফিল্ডে আসল `employee.id` (UUID) ব্যবহার হয়; না হলে প্লেসহোল্ডার দিয়ে এন্ডপয়েন্ট হিট হয় (স্ট্যাটাস 400/401 প্রত্যাশিত)।

4. **টাস্ক চালানো:** ক্রেডেনশিয়াল না থাকলেও টাস্কগুলো আর স্কিপ হয় না; সব এন্ডপয়েন্টই হিট হয়, তাই লোড ও লেটেন্সি মাপা যায়।

## ডামি ইউজার দিয়ে টেস্ট (কমান্ড)

টেস্টের জন্য অস্থায়ী ইউজার তৈরি করে টেস্ট চালিয়ে পরে মুছে দিতে পারেন:

```bash
# ১. ডামি ইউজার তৈরি (একবার)
docker compose exec web python manage.py create_locust_test_user

# ২. লকাস্ট চালান (কন্টেইনারে host = web:8000, তাই ALLOWED_HOSTS-এ 'web' থাকা লাগে – settings-এ যোগ করা আছে)
docker compose exec -T -e LOCUST_USE_DUMMY_USER=1 web locust -f loadtests/locustfile.py --host=http://web:8000 --users 50 --spawn-rate 10 --run-time 1m --headless

# ৩. টেস্ট শেষে ডামি ইউজার মুছে দিন
docker compose exec web python manage.py remove_locust_test_user
```

ডামি ক্রেডেনশিয়াল (locustfile-এ শুধু `LOCUST_USE_DUMMY_USER=1` দিলে ব্যবহৃত):  
`locust-test@genesis.local` / `LocustTestPass123`

**নোট:** লগইন ১০০% সফল; বাকি রিকোয়েস্টে ৪২৯ (Too Many Requests) DRF থ্রটলিং এর জন্য – লোড টেস্টে লিমিট বাড়াতে `REST_FRAMEWORK['DEFAULT_THROTTLE_RATES']` বা view-level throttle সাময়িকভাবে বাড়ানো যেতে পারে।

## সাকসেসফুল টেস্ট (2xx) চালাতে

1. ডাটাবেজে কমপক্ষে একটি এমপ্লয়ি থাকতে হবে এবং তার পাসওয়ার্ড সেট থাকতে হবে  
   (উদাহরণ: `python manage.py set_employee_password employee@example.com` বা অ্যাডমিন থেকে)।

2. ডকার ওয়েব কন্টেইনারের জন্য env সেট করে লকাস্ট চালান:

   ```bash
   docker compose exec -e LOCUST_TEST_EMAIL=employee@example.com -e LOCUST_TEST_PASSWORD=yourpassword web \
     locust -f loadtests/locustfile.py --host=http://web:8000 --users 100 --spawn-rate 15 --run-time 1m --headless
   ```

   Windows PowerShell-এ এক লাইনে:

   ```powershell
   $env:LOCUST_TEST_EMAIL="employee@example.com"; $env:LOCUST_TEST_PASSWORD="yourpassword"
   docker compose exec -T web locust -f loadtests/locustfile.py --host=http://web:8000 --users 100 --spawn-rate 15 --run-time 1m --headless
   ```

   (নোট: `exec` দিয়ে রান করলে env ভ্যারিয়েবল কন্টেইনারের ভিতরে না গেলে, `docker-compose.yml`-এ `environment:` সেকশনে এই দুই ভ্যারিয়েবল যোগ করে দিতে হবে।)

3. এইভাবে চালালে লগইন 200 এবং log-location / log-location-bulk / my-attendance যথাক্রমে 201/200 পাওয়ার কথা।
