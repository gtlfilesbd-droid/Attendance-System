# Store listing screenshots

Place your **Play Store** and **App Store** screenshots here before uploading (optional; for version control or team reference).

## What to capture

See **[BUILD_AND_RELEASE.md](../BUILD_AND_RELEASE.md#store-listing-screenshots--descriptions)** for the full table. Summary:

| # | Screen       | Content |
|---|--------------|--------|
| 1 | Login        | Email/password fields, app title |
| 2 | Home         | Greeting, time, tracking status, START DUTY, action cards |
| 3 | Attendance   | List of attendance cards with date, times, status |
| 4 | Route map    | Map with route and distance/points |
| 5 | Profile      | Name, ID, email, department, Logout |

- Use a **phone** (and optionally tablet for Play).
- **Resolution:** at least 1080px on the long side; follow store requirements.
- Use **sample data** only; no real personal data.

## Naming (optional)

Example: `01-login.png`, `02-home.png`, `03-attendance.png`, `04-route.png`, `05-profile.png`.
